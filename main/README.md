## 진행자 화면

`view.html`은 진행자가 실시간으로 확인하는 읽기 전용 페이지입니다. 관리자 비밀키로 로그인하고, 관리 페이지 탭 바의 **진행자 화면** 링크로도 열 수 있습니다.

- 방송 중인 화면·경기, 대기 타이머 남은 시간
- 방송 중 경기의 판별 곡·기준점수·선수별 난이도(버튼·패턴)와 점수·합산·차이와 경기 합계(앞서는 팀, 승자 확정)
- 오른쪽 대진표에서 다른 경기를 눌러 볼 수 있고, 방송 중 경기를 다시 누르면 따라가기로 돌아갑니다
- 기준점수를 막 뽑은 판은 오버레이 릴이 멈출 때까지 '추첨 중…'으로 가립니다

난이도는 관리 페이지 **경기 진행** 탭에서 선수 점수 칸 옆의 버튼(4B·5B·6B·8B)과 패턴(NM·HD·MX·SC)으로 판마다 선수별로 고릅니다. 자선곡을 다시 불러와 곡이 바뀐 판은 난이도가 지워집니다. 방송 오버레이에는 나오지 않습니다.

**팀·자선곡** 탭에서 자선곡마다 팀장·팀원 난이도를 미리 정해 둘 수 있습니다(팀 카드의 선수 1이 팀장). 곡을 경기에 넣을 때(6강·4강 불러오기, 결승 추첨) 두 팀의 팀장에게는 팀장 난이도, 팀원에게는 팀원 난이도가 들어가고, 이후 선수별로 고칠 수 있습니다. 곡을 넣은 뒤 대진이 바뀌면 경기 화면에 경고가 뜨니 다시 불러오거나 다시 추첨하세요.

## 방송 오버레이

OBS 브라우저 소스(1920×1080)에 `overlay.html`을 넣습니다. 화면은 관리 페이지 **경기 진행** 탭의 **방송 화면** 버튼으로 바꿉니다.

| 주소 | 화면 |
|---|---|
| `overlay.html` | 관리 페이지에서 고른 화면 (대기·게임설명·대진표·트랙리스트·빈 화면) |
| `overlay.html?scene=standby` | 대기화면 + 타이머 고정 |
| `overlay.html?scene=rule` | 게임설명 고정 |
| `overlay.html?scene=bracket` | 대진표 고정 |
| `overlay.html?scene=track` | 트랙리스트 고정 (6강·4강은 2칸, 결승은 3칸) |
| `overlay.html?scene=blank` | 빈 화면 고정 (로고와 배경만) |

화면이 바뀔 때의 전환 효과(컷·페이드·스와이프·슬라이드·색상으로 페이드)와 방향·색·시간도 같은 곳에서 화면마다 따로 고릅니다. 효과는 그 화면으로 바뀔 때 쓰이고, **모든 화면에 적용**으로 한 화면의 설정을 전체에 복사할 수 있습니다. OBS 기본 전환과 같은 동작을 오버레이 안에서 재현한 것입니다.

OBS 장면을 직접 나누고 싶으면 `?scene=`으로 고정한 소스를 장면마다 넣으면 됩니다. 배경 시안은 `main_overlay/`에 있습니다.
데이터는 `tourney/main/live`(공개 읽기)에 있고, 선수별 점수는 `tourney/main/scores`(관리자만)에 따로 둡니다. 구조는 `common.js` 맨 위 주석을 참고하세요.

경기 진행 탭의 **곡 초기화**는 그 경기의 판별 곡·기준점수·난이도·점수·승자를 지워 곡을 넣기 전으로 되돌립니다. 결승은 추첨 전 상태가 되어 **결승 3곡 추첨**을 다시 할 수 있고, 6강·4강은 **트랙리스트에 띄우기**를 누르면 자선곡을 새로 불러옵니다.
